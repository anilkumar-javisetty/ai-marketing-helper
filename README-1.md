Readme.md# AI Marketing Helper

A simple web tool that uses AI to write marketing content (cold email, Instagram post, WhatsApp offer message, product description) in English, Telugu or Hindi.

- Built with HTML, CSS and JavaScript
- Enter business name, product and customer, then tap Generate
- Can open pre-filled WhatsApp messages for mobile numbers

Note: the AI generation works inside Claude (artifact link). Opening the HTML file elsewhere shows the form only.
